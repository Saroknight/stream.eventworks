For troubleshooting frame rate. Leave on Auto unless you're testing.

Start your game first and keep it moving. Pick the game's screen when asked. Takes about 45 seconds and nobody sees the test.

Tips for the best stream
  • Use Chrome or Edge.
  • To include game sound on Windows, choose Entire screen and tick Share system audio. For a browser tab, tick Share tab audio.
  • If a fullscreen game shows black, switch the game to borderless windowed.
  • Keep this tab open while you stream. You can minimize it.
